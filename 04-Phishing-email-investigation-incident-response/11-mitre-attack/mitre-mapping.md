# MITRE ATT&CK Mapping

## T1566 — Phishing

**Technique:** T1566

**Description:**

The simulated incident involved a phishing email designed to convince the recipient to interact with a suspicious account verification link.

## T1566.002 — Spearphishing Link

**Technique:** T1566.002

**Observed Behavior:**

The email contained a suspicious URL presented as an account verification link.

**Evidence:**

- Suspicious sender domain
- Brand impersonation
- Urgent account verification request
- Embedded external URL

## Analyst Assessment

The observed email behavior is consistent with the phishing and spearphishing link techniques.

Additional MITRE ATT&CK techniques will only be mapped if corresponding endpoint or network behavior is observed during the investigation.
